# Create a garbage collector simulator


create a tug of war game in between consurmer and producer
rules: 
    1. producer tries to make the avaliable memory reach its max limit
    2. consumer tries to make the avaliable memory reach its min limit
    3. memory is fixed constant resource which will remain constant
    4. random effects will be applied to producer and consmers on time interval, like adding more of a kind, increasing or decreading its rate of production or consumptions.
